# Swyby Backend API

Python backend powering activity recommendations and user management.

Part of [Swyby](https://swyby.io) ecosystem.

## API Endpoints

| Endpoint | Description |
|----------|-------------|
| `/api/v1/activities` | Discover activities |
| `/api/v1/plan` | Generate day plan |
| `/api/v1/events` | Local events |
| `/api/v1/user` | User preferences |

## Tech Stack

- Python 3.12
- Flask
- PostgreSQL
- Redis
- JWT authentication
